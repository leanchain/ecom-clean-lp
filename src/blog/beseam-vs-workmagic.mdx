## TL;DR

WorkMagic is positioned around **incrementality-based attribution** and automated holdout execution for ad platforms.

Beseam is positioned around **Shopify change incident response**: if conversion drops after a storefront change, Beseam ties it to the exact diff and guides rollback/remediation.

## What WorkMagic claims (from the research you shared)

- Incrementality-based attribution + data-driven attribution.
- Lift test frameworks and methodologies (2-cell/3-cell, PTM vs LTM).
- Some automation via API to set up/tear down ad-platform holdouts; “real-time monitoring” in the test context.

## Beseam’s “interventions” are store changes

Where WorkMagic automates *ad-platform holdouts*, Beseam automates *storefront safety*:

- change capture across high-risk Shopify objects (theme, promos, pixels, checkout customizations)
- post-change KPI monitoring
- incident→change attribution
- rollback/runbooks + verification
