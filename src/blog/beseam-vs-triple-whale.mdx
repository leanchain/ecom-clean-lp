## TL;DR

Triple Whale is built for **marketing measurement**: a unified “closed loop” of MMM + attribution + incrementality experiments.

Beseam is built for **commerce operations**: detect and attribute conversion incidents caused by **store-controlled changes** (theme, promos, pixels, checkout customizations), then guide rollback/runbooks.

## What Triple Whale claims (from the research you shared)

- Compass: unified measurement workflow combining **MMM + MTA + incrementality**, calibrated weekly.
- Self-serve incrementality dashboard (GeoLift + Meta Conversion Lift) with power analysis and lift metrics.
- Pixel installation on Shopify via theme app block / web pixels (tracking plumbing).
- Profitability dashboards (COGS/expenses) for net profit visibility.

## The difference in “interventions”

### Triple Whale: media interventions

- Change **spend/exposure** to measure incremental lift.
- Calibrate reporting and planning using experiments and models.

### Beseam: storefront interventions

- Capture and normalize **Shopify change events** (theme publishes, discount eligibility, pixel edits, checkout extensions, app embeds/blocks).
- Detect KPI anomalies (CVR, checkout-start, rev/session).
- Attribute incidents to **specific diffs**, then recommend keep/rollback/iterate.

## When agencies pick which

- Choose **Triple Whale** when the mandate is: “prove what marketing drove growth (incrementality) and report it weekly.”
- Choose **Beseam** when the mandate is: “ship store improvements fast without breaking revenue—and prove what changed when KPIs dip.”
